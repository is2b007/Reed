# Reed 0.2.3

A redesigned Settings window on desktop.

## Settings

- **New layout.** A sidebar for Appearance, Git autosave and Updates, with each setting on one row: label and short explanation on the left, control on the right.
- **Theme tiles.** Choose System, Light or Dark from small previews.
- **Switches** for Git autosave and automatic update checks, and normal-sized buttons and menus.
- **Clearer status.** Updates shows "Up to date" or the new version with an Install and restart button; Git autosave shows the actual last result and time.
- Works in light and dark mode and in narrow windows.

## Updating

From 0.2.2, use **Check for updates** in Settings → Updates. Android installs over 0.2.2 directly.
